# Hi, I'm Tanay

I'm a junior at NCSSM (North Carolina School of Science and Mathematics) and I want to study computer engineering. I like building things that cut down on wasted energy, water and time.

## Things I've built

- [Charlotte Rain-Skip Check](https://github.com/tanaymishra1/charlotte-rain-skip): uses 10 years of NOAA weather data to check a sprinkler timer in Charlotte. 15.4% of its waterings came right after real rain. A rain-aware schedule saves 9.9% of waterings, or 16.9% if it also knows that day's rain. I also tested a machine learning rain model: it barely beat chance (AUC 0.61) and was no more accurate than always guessing no rain.
- [Engineering Trade-Off Visualizer](https://github.com/tanaymishra1/engineering-tradeoff-visualizer): a web app that scores design options on speed, torque and cost and ranks the ones you save. [Try it here](https://tanaymishra1.github.io/engineering-tradeoff-visualizer/).
- [Engineering Trade-Off Simulator](https://github.com/tanaymishra1/engineering-tradeoff-simulator): the Python command-line version, which is where the idea started.
- GalaXiuZ: my first website, a concept site for an all-in-one platform covering learning, entertainment and more. I'm rebuilding it from scratch, and the code is private.
